# رزومه آنلاین من

این ریپازیتوری شامل کد سایت رزومه شخصی من است که با استفاده از **HTML**، **CSS** و **JavaScript** ساخته شده و از طریق GitHub Pages به صورت زنده در دسترس قرار دارد.


## 📋 درباره این پروژه
این سایت شامل اطلاعات زیر است:
- معرفی و بیوگرافی کوتاه
- سوابق تحصیلی
- سوابق شغلی و تجربیات کاری
- مهارت‌ها و تخصص‌ها
- نمونه‌کارها و پروژه‌ها
- راه‌های ارتباطی

## 🛠️ تکنولوژی‌های استفاده شده
- HTML
- CSS
- JavaScript

## 📁 ساختار پروژه
```
├── index.html      # صفحه اصلی سایت
├── style.css       # استایل‌های سایت
├── script.js       # اسکریپت‌های تعاملی سایت
```
